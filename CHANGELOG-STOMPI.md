# Stompi changes

## v0.1.0-stompi — source release

- Publish native Stratum V2 solo-mining source for Stompi.
- Support STP payout addresses, bare STP identities and optional worker suffixes.
- Reject malformed STP identities instead of silently selecting donation behavior.
- Account Vardiff using accepted work at each job's own target.
- Include the external Template Provider's idle-socket CPU patch.
- Add private local configuration generation and a targeted GitHub CI workflow.
- Preserve SRI licensing, attribution and upstream reference docs.

Cargo crate versions and internal upstream names are unchanged. This tag identifies the Stompi source package, not a new upstream SRI version. Public endpoints and validation evidence are documented as of 2026-10-02.
