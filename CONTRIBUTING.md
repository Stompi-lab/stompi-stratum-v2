# Contributing to Stompi Stratum V2

For Stompi-specific changes, open issues and pull requests in Stompi-lab/stompi-stratum-v2. Preserve original licensing and authorship notices. Run the targeted test commands in docs/BUILD.md. Keep private configuration and runtime data out of commits.

Upstream SRI conventions and contribution workflow are preserved in [docs/upstream/CONTRIBUTING.md](docs/upstream/CONTRIBUTING.md); upstream-only proposals belong in the original project.
